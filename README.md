# 這是什麼？

這是一個「健康記錄」App 的完整原始碼，設計給中高齡使用者記錄血壓、血糖，
方便回診時跟醫生溝通。這份壓縮檔裡面裝的不是一個可以直接點開的軟體，
而是「食譜」──工程師（或會架站的人）拿到之後，照著食譜做，
就能把它變成一個手機、電腦都能打開的正式網站。

如果您不打算自己動手，最簡單的做法是：
**把這個資料夾整個交給工程師或接案人員，附上下面這段文字給他看就好。**

---

## 給工程師的一句話說明

這是一個 Next.js 14（App Router）專案，UI 用 Tailwind CSS，
圖表用 recharts，圖示用 lucide-react。資料目前用瀏覽器
localStorage 保存（單機版，未串接後端）。
執行 `npm install` 後 `npm run dev` 可在本機預覽；
正式上線建議直接部署到 Vercel（GitHub 連動、免費方案即可）。
若要支援多裝置同步（例如子女在外地查看父母數據），
需另外串接資料庫服務（如 Supabase）並加上登入驗證，
程式碼中標記了 `【資料層】` 的地方就是需要調整的位置。

## 如果您想自己嘗試看看（不需要真的懂程式）

以下是「照著打字就好」的步驟，在電腦上操作（Mac 或 Windows 都可以）：

### 步驟 1：安裝一個叫 Node.js 的工具
這是讓電腦「看得懂」這份食譜的工具。
到 https://nodejs.org 下載並安裝（選左邊寫「LTS」的版本），
一路按「下一步」安裝完成即可。

### 步驟 2：打開「終端機」
- Mac：在啟動台搜尋「終端機」（Terminal）
- Windows：在開始選單搜尋「PowerShell」

### 步驟 3：移動到這個資料夾
把這份解壓縮後的資料夾拖進終端機視窗，
或是輸入（把路徑換成您實際解壓縮的位置）：
```
cd 資料夾路徑
```

### 步驟 4：安裝所需元件
在終端機輸入：
```
npm install
```
這一步會花一點時間，是在幫這個網站把需要的零件都下載齊全。

### 步驟 5：在自己電腦上試跑看看
```
npm run dev
```
接著打開瀏覽器，輸入 `http://localhost:3000`，
就會看到完整可以操作的 App 了（僅限您自己這台電腦看得到）。

### 步驟 6：正式讓客戶能用（讓全世界都打得開）
這一步建議交給工程師處理，或參考先前提供的「部署到 Vercel」步驟：
把這個資料夾上傳到 GitHub，再到 vercel.com 做連結，
幾分鐘後就會拿到一個正式網址，例如
`https://您的專案名稱.vercel.app`，
之後就可以把這個網址傳給客戶，用手機瀏覽器打開，
再選「加入主畫面」，就會像一個真正的 App 圖示一樣好用。

## 目前這個版本「能做」與「還不能做」的事

**能做：**
- 記錄血壓、血糖，數值超標會有溫和提示
- 看 7 / 30 / 90 天的走勢圖
- 一鍵切換「看診模式」，給醫生看重點整理
- 資料會保存在使用者自己的手機瀏覽器裡，關掉 App 不會不見

**還不能做（如果客戶需要，要請工程師加）：**
- 不同手機看到同一份資料（例如家人共同查看）
- 多位使用者（例如照顧兩位長輩）分開記錄
- 修改或刪除已經記錄的數值
- 真正產出 PDF 檔案（目前是用手機的「列印」功能存成 PDF）
