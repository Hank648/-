# 健康紀錄 App（血壓・血糖追蹤）

專為中高齡使用者與門診看診溝通設計的簡易 Web App。  
資料存在使用者自己手機瀏覽器的 localStorage，關掉再開也不會不見。

## 功能

- 快速記錄血壓（收縮壓／舒張壓／心率）與血糖（含用餐狀態）
- 溫和異常提示（偏高／注意／正常）
- 7 / 30 / 90 天走勢圖
- 近 30 天統計卡片（平均值、達標率）
- **看診模式**：14 天摘要 + 表格 + 一鍵列印／分享文字
- 連續記錄徽章
- 一鍵分享今日摘要（可貼到 LINE）
- 可刪除歷史紀錄
- 初次開啟自動帶入 14 天 Demo 資料

## 本機預覽

```bash
npm install
npm run dev
```

打開 http://localhost:3000

## 部署到 Vercel（傳連結就能用）

1. 把整個資料夾上傳到 GitHub（或直接用 Vercel 的「Import」）
2. 到 [vercel.com](https://vercel.com) 登入，點「Add New Project」
3. 選擇這個 repo，直接 Deploy（Next.js 會自動偵測）
4. 幾分鐘後會得到一個網址，例如 `https://health-tracker-xxx.vercel.app`
5. 把這個網址傳給家人／自己，用手機瀏覽器打開後可「加入主畫面」當 App 用

完全免費（Vercel 免費方案足夠）。

## 注意事項

- 資料只存在「當下這台裝置的瀏覽器」，換手機或清除瀏覽器資料就會不見。
- 若需要家人一起看同一份資料，之後可再串接 Supabase 等後端。
